# 💎 Shets Jewellers

A modern and responsive jewellery website developed using React, Vite, and Tailwind CSS. The application provides customers with an elegant shopping experience by showcasing jewellery collections, bridal collections, product details, and custom order options.

## 🚀 Features

- Responsive and modern UI
- Home page with featured collections
- Jewellery collections page
- Bridal collection page
- Product details page
- Custom jewellery order page
- Contact page
- Search functionality
- Shopping cart drawer
- User authentication modal
- Privacy, Shipping, Return, and Terms pages

## 🛠️ Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- HTML5
- CSS3

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/shets-jewellers.git
```

Navigate to the project folder

```bash
cd shets-jewellers
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
